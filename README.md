## 🔑 How to Get Telegram API ID & API Hash

To use Telegram API-based applications, you can create Telegram API credentials through Telegram's official developer portal.

### Step 1: Visit Telegram

Go to:

https://my.telegram.org

Sign in using your Telegram account.

### Step 2: Open API Development Tools

Visit:

https://my.telegram.org/apps

Open the **API Development Tools** section and complete the required application information.

### Step 3: Get API Credentials

Telegram provides an **api_id** and **api_hash** that can be used for Telegram API authentication.

Keep your API credentials private. **Never publish your `api_hash` or other sensitive authentication credentials in a public GitHub repository.**
